Vaka 0.5.0 brings Vaka into Grafana: a native data source plugin, a time series API built for dashboards and a live event stream. Country lookups now work out of the box with a bundled GeoIP database.

## Highlights

- **Grafana data source plugin** (`hellsoft-vaka-datasource` 0.1.0, released separately as `grafana/v0.1.0`). Query errors over time, issues, sessions and crash-free rate, release health and adoption, analytics, funnels, performance, Web Vitals, logs, traces, monitors and incidents. Every time series can drive Grafana alerting. Grafana Live streams new errors, events and transactions. It also adds template variables and annotations for releases, new issues, regressions and incidents. The API token stays on the Grafana server. See `docs/grafana.md`.
- **Time series API for dashboards.** `interval` accepts `minute` and durations such as `5m`, `15m` and `6h` (up to 2000 buckets). `fill=true` returns every bucket, and `group_by` splits a series into its top N groups. New endpoints `GET /api/v1/projects/{p}/errors/timeseries`, `/performance/timeseries` and `/sessions/timeseries` have matching MCP tools. `GET /api/v1/me` now reports `server_version` and `capabilities`.
- **Live stream (SSE).** `GET /api/v1/projects/{p}/stream` pushes new errors, analytics events and spans as Server-Sent Events as soon as they are stored. See `docs/realtime.md`.
- **CORS for browser dashboards** (opt-in). `VAKA_API_CORS_ORIGINS` lets the listed origins call `/api/v1` with a bearer token.
- **GeoIP works out of the box.** Before, the country was empty for every event unless you configured a database. Vaka now bundles the DB-IP IP to Country Lite database (CC BY 4.0) and checks weekly for a newer one, which it keeps in `$VAKA_DATA_DIR/geoip/`. `VAKA_GEOIP=false` turns lookups off, `VAKA_GEOIP_UPDATE=false` keeps only the bundled file, and `VAKA_GEOIP_DB` points at your own MaxMind or DB-IP `.mmdb`.
- **Single-VM deploys.** `deploy/hetzner/` has a setup script, compose file and ClickHouse memory caps for running everything on one server, plus tooling to move from Fly.io.
- **Icons.** Vaka has an icon and favicons, and the docs site has social preview tags.

## Upgrading

No database migrations and no breaking API changes from 0.4.0. Two things to know:

- Countries now fill in from the client IP by default. If you don't want that, set `VAKA_GEOIP=false`. The weekly update check downloads from `download.db-ip.com`; set `VAKA_GEOIP_UPDATE=false` or `VAKA_GEOIP_UPDATE_URL` (a mirror) if the server shouldn't reach it.
- If you're coming from 0.3.0, read the "Upgrading" section of the 0.4.0 notes first: it has the configuration changes from the security review.

Python (`vaka-sdk`) and Rust (`vaka-sdk`) 0.4.0 were never published to PyPI and crates.io, so 0.5.0 is the next version there after 0.3.0.

## Install

Server (multi-arch image, amd64 and arm64):

```sh
docker pull ghcr.io/erikhellman/vaka:0.5.0
```

SDKs:

| Platform | Package |
| --- | --- |
| Browser | `npm i @hellsoft/vaka-browser` (or `/sdk/vaka.js` from your instance) |
| Node.js | `npm i @hellsoft/vaka-node` |
| Python | `pip install vaka-sdk` |
| Go | `go get github.com/ErikHellman/vaka/sdks/go@v0.5.0` |
| Rust | `vaka-sdk = "0.5"` |
| iOS, macOS, tvOS | `.package(url: "https://github.com/ErikHellman/vaka", from: "0.5.0")` |
| Grafana | Zip on the `grafana/v0.1.0` release (not in the Grafana catalog yet) |

The `vaka` CLI binaries for Linux (x86_64, aarch64), macOS (Apple silicon) and Windows (x86_64) are attached below.

Docs: https://vaka.hellsoft.se (also served by every instance at `/docs/` and `/llms.txt`).

## Known gaps

- **Android SDK, Gradle plugin and JVM SDK are not on Maven Central yet** (the `se.hellsoft` namespace is still being verified). Include them from source; see `docs/install/android.md` and `docs/install/jvm.md`.
- **.NET packages are not on NuGet yet.** Build them from `sdks/dotnet` with `dotnet pack` (see `docs/releasing/dotnet.md`).
- **The Grafana plugin is not in the Grafana catalog yet.** It needs a grafana.com submission (see `docs/releasing/grafana.md`). Until then, load it as an unsigned plugin or sign it privately.
