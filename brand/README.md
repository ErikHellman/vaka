# Vaka brand assets

"Vaka" is Swedish for "keep watch": the mark is an eye with a pulse line through it.

- `vaka.svg` / `vaka-512.png`: main icon (green tile). Used on vaka.hellsoft.se; the
  site's copies live in `site/public/` (favicon.svg, favicon.ico, apple-touch-icon.png).
- `vaka-admin.svg` / `vaka-admin-512.png`: admin web app variant (dark tile, amber badge),
  served by the server from `crates/vaka-server/assets/`.
- `og-image.png`: 1200x630 social preview for the site (`site/public/og-image.png`).

Colours: green `#2f6f4f`, mint `#7cc49d`, ink `#1d1d1b`, paper `#fbfbf9`, amber `#e8a33d`.
ICO files hold 16, 32 and 48 px renders; apple-touch icons are full-bleed 180 px squares.
